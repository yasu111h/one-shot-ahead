# ONE SHOT AHEAD（仮題）

iOS向け3D長距離スナイパーゲーム（Godot 4）。

コンセプト：一瞬だけ開く「命中の窓」に、リード（偏差撃ち）した1発をねじ込む快感。

- 精密ミッションモード（弾数制限・1発の重み）
- 物量防衛モード（迫り来る敵を撃ち落とす）
- 標的は人間・リアル表現・血なし
- 世界観：現代ミリタリー＋ドローン等の近未来ガジェット

## 操作（PC）

- 視点：右ドラッグ（スマホは画面右側ドラッグ）
- 発射：左クリック / FIREボタン（Fキー予備）
- スコープ：Qキー / ホイール / SCOPEボタン（1x→4x→8x）

## 弾道デバッグモード（F3・デバッグビルド専用）

狙点・実弾・リプレイの弾道が一致しているかを目と数値で検証するモード。
実装は `core/debug/trajectory_debug.gd`。リリースビルドでは無効。

- **F3**：弾道デバッグ表示のON/OFF
  - **緑線＋AIM**＝発射の瞬間にレティクルが指していた線と狙点
  - **赤線＋REAL**＝実弾が実際に通った軌跡と着弾点。狙点からの落下量（DROP）・横ズレ（SIDE）を数値表示（直線弾道なら0のはず）
  - **黄線＋REPLAY**＝バレットカム（リプレイ）の弾の軌跡と終点。実弾道との最大乖離（PATH DEV）を数値表示
  - 命中確定弾は実弾を飛ばさない設計のため、ダメージなしの「ゴースト実弾」を裏で飛ばして赤線を記録する
- **Tab**：視点切替（通常 → 弾道を真横から → 着弾点アップ → 通常…）
  - 弾道は視線方向と重なるため、正面からは線の重なり・落差が見えない。真横視点で確認する
- 数値パネル（左上）：狙点座標・着弾座標・DROP・リプレイ終点とのGAP・最大乖離を常時表示
