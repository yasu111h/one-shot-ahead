# LONGSHOT SNIPER

iOS向け3D長距離スナイパーゲーム（Godot 4）。

コンセプト：高所から、離れた場所の悪人だけを、静かな一撃で仕留める正義の狙撃。
命中は弾丸追尾のスローカメラ＋距離スタンプ（例「731m HEADSHOT」）で魅せる。

- 精密モード（弾数制限・1発の重み。悪人だけを撃ち抜く）
- 応戦モード（敵が撃ち返してくる。被弾でFAIL）
- 物量モード（迫り来る大量の敵を撃ち捌く）
- 標的は人間・リアル表現・血なし。民間人・人質の誤射は即失敗
- 世界観：現代ミリタリー＋ドローン等の近未来ガジェット
- ステージ：夜の都市（夜/夕方）・夜の埠頭・夜明けの砂漠の検問所・射撃場

## 操作（PC）

- 視点：右ドラッグ（スマホは画面右側ドラッグ）
- 発射：左クリック / FIREボタン（Fキー予備）
- スコープ：Qキー / ホイール / SCOPEボタン（1x→4x→8x）

## 弾道デバッグモード（F3・デバッグビルド専用）

狙点・実弾・リプレイの弾道が一致しているかを目と数値で検証するモード。
実装は `core/debug/trajectory_debug.gd`。リリースビルドでは無効。

- **F3**：弾道デバッグ表示のON/OFF
  - **緑線＋AIM**＝発射の瞬間にレティクルが指していた線と狙点
  - **赤線＋REAL**＝実弾が実際に通った軌跡と着弾点。狙点からの落下量（DROP）・横ズレ（SIDE）を数値表示（直線弾道なら0のはず）
  - **黄線＋REPLAY**＝バレットカム（リプレイ）の弾の軌跡と終点。実弾道との最大乖離（PATH DEV）を数値表示
  - 赤線は実弾と同一の積分・当たり判定で発射の瞬間に一括シミュレート＝撃った直後に全長が出る（命中確定弾・長距離でも待ち時間なし）
- **Tab**：視点切替（通常 → 弾道を真横から → 着弾点アップ → 通常…）
  - 弾道は視線方向と重なるため、正面からは線の重なり・落差が見えない。真横視点で確認する
- 数値パネル（左上）：狙点座標・着弾座標・DROP・リプレイ終点とのGAP・最大乖離を常時表示
- AIM/REAL/REPLAYのマーカー（球＋名前）は約3秒で自動消去（線とパネルは次の発射まで残る）

## 重力弾道の切り替え（GRAVITYボタン）

- HUD右上の **GRAVITY: ON/OFF** ボタンで重力弾道（放物線）を切り替えられる（設定は保存される）
- OFF（既定）：直線弾道＝狙った点にそのまま当たる
- ON：弾が放物線を描き、狙点より下に落ちる（200m先で約2m）。実弾・着弾予測・リプレイの
  すべてが同じ計算を参照するので、リプレイ弾も同じ弧を描く
- 弾道デバッグ（F3）と併用すると「緑＝まっすぐな狙い」「赤・黄＝下に落ちる実弾道」の分離が見える
